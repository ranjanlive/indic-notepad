# Changelog

## 0.1.0-beta.1 · 26 October 2026

First native Windows x64 beta. Multi-tab editing, strict UTF-8/UTF-16, safe save
conflicts, recovery, syntax, bounded search/replace, themes, focus mode, command
palette, folder explorer and native reading pane. Portable ZIP and per-user
installer with notices/checksums. No embedded browser or background service.

This is a scoped beta; the original proposal's full 1.x feature/performance and
clean-machine acceptance matrix is not claimed. See docs/REQUIREMENTS.md.
