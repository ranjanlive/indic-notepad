# Documentation map

- guide.md: everyday commands and release process.
- PRODUCT_STANDARD.md: company-wide folder and ownership rules.
- design/: product-specific design documentation.
- store/store-listing.json: editable store listing draft; review before submission.
- website/: current editable product metadata and privacy JSON.
- schemas/: machine-readable contracts.
- verification/: concise evidence summary and ignored local build logs.
- archive/: ignored historical plans/delivery drafts preserved for reference.
